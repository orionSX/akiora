# Frontend

Локальный запуск без Docker:

```sh
pnpm install
pnpm dev
```

Astro поднимется на `http://localhost:4321`.

Во время локальной разработки все запросы на `/api/*` проксируются в Python backend на `http://127.0.0.1:8000`, поэтому фронт работает без отдельной nginx-прослойки и без CORS-настроек в браузере.

Перед запуском фронта подними backend `core` на `8000`.
